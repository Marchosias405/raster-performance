# Performance Analysis of GIS-Style Raster Processing

This project uses synthetic GIS-style raster processing as a workload for studying computer systems performance in C++ on x86-64.

The main goal is to experimentally investigate CMPT 295 concepts including:

- compiler optimization
- compiler-generated assembly
- automatic vectorization
- SIMD/vector instructions
- memory locality and cache behavior
- branch predictability
- input-size effects
- performance measurement

The project is not intended to be a complete GIS application.

## Planned Workloads

The project will use two main operations:

1. 3x3 raster smoothing
2. threshold classification

Multiple implementations and input patterns will be compared where they help demonstrate the systems concepts above.

## Data

No external dataset is used.

The project uses synthetic GIS-style raster data generated by its own C++ code. The general raster generator is deterministic, so the same dimensions produce the same values.

For each cell, the generator uses its 1D array index:

```text
value = (index % 1000) / 1000.0
```

This produces values from `0.000` through `0.999`, with the pattern repeating every 1000 cells.

Data generation will be performed separately from the timed performance kernels so that dataset creation is not included in kernel timing.

Small hand-created grids will also be used for correctness tests where results should be easy to calculate manually.

- Ubuntu 24.04.1 LTS under WSL2
- x86-64
- GCC/G++ 13.3.0
- Intel Core i9-13900H
- AVX and AVX2 CPU support reported
- Valgrind 3.22.0 available
- GNU `/usr/bin/time` available

`perf` is not currently available for the installed WSL2 kernel. Final performance-counter experiments will therefore require a Linux environment where `perf` is verified to work.
